# Aptitude Test Simulator

적성검사의 복합 작업 상황을 연습하기 위해 제작한 Unity 기반 모의 시험기입니다.

사용자는 제한 시간 동안 시각적 타이밍 판단, 청각적 숫자 인식, 저장 공간 관리를 동시에 수행해야 합니다. 여러 정보를 동시에 처리하는 상황을 게임 형태로 구현하는 것을 목표로 제작했습니다.

## 프로젝트 개요

- 개발 환경: Unity 6.2 (`6000.2.9f1`)
- 개발 언어: C#
- 시험 시간: 120초
- 지원 플랫폼: PC
- 개발 형태: 개인(토이) 프로젝트

## 주요 기능

### 1. 시각적 숫자 판정

1부터 4까지의 숫자가 무작위 레인에서 아래로 이동합니다.

사용자는 숫자가 기준선에 도달했을 때 해당 숫자 키를 눌러야 합니다. 입력 시점과 저장 공간의 상태에 따라 성공 또는 실패가 결정됩니다.

### 2. 청각적 숫자 판정

시험 도중 1부터 9까지의 숫자 음성이 일정한 간격으로 재생됩니다.

사용자는 숫자 `7`을 들었을 때 스페이스바를 눌러야 합니다.

- 7을 듣고 입력: 정답
- 다른 숫자에서 입력: 오답
- 7에 반응하지 않음: 미응답

### 3. 색상별 저장 공간 관리

화면에 등장하는 숫자는 빨강, 노랑, 파랑, 초록 중 하나의 색상을 가집니다.

입력에 성공한 숫자는 해당 레인의 상자에 저장됩니다. 현재 색상의 저장 공간이 가득 찬 경우 새로운 상자를 추가해야 숫자를 처리할 수 있습니다.

이 과제는 타이밍 판단과 동시에 현재 저장 공간을 확인하도록 설계했습니다.

## 조작법

| 입력 | 동작 |
|---|---|
| `1` ~ `4` | 해당 번호의 숫자 처리 |
| `Shift + 1` ~ `Shift + 4` | 해당 레인에 상자 추가 |
| `Space` | 음성으로 7이 들렸을 때 응답 |
| `Esc` | 게임 종료 |

숫자 키패드의 `1`부터 `4`까지도 사용할 수 있습니다.

## 게임 진행

1. 타이틀 화면에서 게임을 시작합니다.
2. 120초 동안 세 가지 과제를 동시에 수행합니다.
3. 화면의 숫자가 기준선에 도달하면 해당 번호를 입력합니다.
4. 필요한 경우 해당 레인의 상자를 추가합니다.
5. 음성으로 숫자 7이 들리면 스페이스바를 누릅니다.
6. 시험이 종료되면 놓친 숫자와 음성 과제 오답 횟수를 확인합니다.

```text
GameManager
├─ 시험 시작과 종료
├─ 전체 시험 시간 관리
└─ 각 과제의 실행 상태 관리

NoteSpawner
├─ 무작위 숫자 생성
├─ 레인 및 색상 선택
└─ 출제 시간 관리

LaneController

└─ 저장 가능 여부 확인

LaneInventory
├─ 상자 개수 관리
└─ 색상별 저장량 관리

├─ 숫자 음성 재생
├─ 숫자 7 응답 판정
└─ 미응답 및 오입력 처리

ScoreSystem
└─ 시각 과제와 청각 과제의 결과 집계
